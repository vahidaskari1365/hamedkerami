# استانداردهای الزامی dr-kermani.com — SEO / AEO / GEO / AIO / SXO

> **این سند قرارداد کیفیت سایت است.** هر صفحه، بخش، کامپوننت یا مقاله‌ای که الان
> هست یا در آینده اضافه می‌شود باید این چک‌لیست‌ها را پاس کند. مرور نهایی هر
> تغییر با همین سند انجام می‌شود؛ آیتم ناموفق = عدم انتشار.

## ۱) پنج استاندارد و معنی‌شان برای این سایت

| استاندارد | مخاطب | هدف عملی در dr-kermani.com |
|---|---|---|
| **SEO** | گوگل/بینگ | رتبه گرفتن برای کلمات «هزینه جراحی فک»، «ایمپلنت پاسداران» و… — ایندکس کامل، canonical درست، Core Web Vitals |
| **AEO** | Answer Engines (لغزنده‌های پاسخ، featured snippet، «People also ask») | هر صفحه در ۴۰–۶۰ کلمهٔ اول «پاسخ مستقیم» دارد؛ FAQ ساختاریافته در همه صفحات محتوایی |
| **GEO** | ChatGPT / Perplexity / Gemini / Copilot | استناد گرفتن در پاسخ‌های AI: llms.txt، اسکیمای کامل، آمار قابل‌استناد، RAG-chunk friendly |
| **AIO** | لغزنده‌های آموزش مدل (GPTBot، ClaudeBot و…) | دسترسی باز به لغزنده‌های AI در robots.txt، فید RSS، endpoint های `/ai/*.json`، ai.txt |
| **SXO** | خود بیمار | تجربه جستجوی عالی: سرعت، موبایل، CTA تلفن/واتس‌اپ همیشه در دسترس، ناوبری روشن، اعتمادسازی (تصاویر قبل/بعد، رزومه) |

**اصل یکپارچه:** محتوایی که برای بیمار خوب، روشن و مستند باشد و برای ماشین
خوانا و ساختاریافته — هر دو را یکجا می‌سازد. هیچ‌کدام قربانی دیگری نمی‌شود.

## ۲) چک‌لیست فنی هر صفحه (SEO + AIO)

- [ ] `metadata` اختصاصی: title (≤۶۰ کاراکتر)، description (۱۲۰–۱۶۰ کاراکتر، شامل کلمه کلیدی و «تهران»)
- [ ] `canonical` مطلق مخصوص همان صفحه + `languages` (fa / en / x-default) در `alternates`
- [ ] **هرگز** آبجکت `alternates` صفحه، بدون `types` فید باشد (لینک RSS حالا سراسری در layout رندر می‌شود)
- [ ] JSON-LD مرتبط: صفحات خدمت → `MedicalProcedure` + `BreadcrumbList`؛ مقالات → `Article` + `FAQPage` + `BreadcrumbList`؛ همه صفحات `Person/Physician` ارجاع به `#physician`
- [ ] اسکیمای Article شامل `author` (ارجاع `#physician`)، `publisher`، `inLanguage: fa-IR`، `lastmod` نامرئی در sitemap
- [ ] URL در `src/app/sitemap.ts` ثبت شود (داینامیک — مقالات خودکار می‌روند) و کانری deploy (`xhtml:` = 0) پاس شود
- [ ] تصاویر: `width/height` صریح، `alt` فارسی توصیفی، `priority` برای تصویر هیرو، `loading="lazy"` برای بقیه
- [ ] HTML بدون JS هم محتوای اصلی را دارد (خزش بدون جاوااسکریپت — ممیزی GEO بند ۱۰)
- [ ] `lang="fa"` و `dir="rtl"` حفظ؛ صفحه انگلیسی `/en` با `lang="en" dir="ltr"`
- [ ] لینک‌های `<a href>` واقعی (نه onClick) تا خزش و Cmd+click کار کند

## ۳) چک‌لیست محتوا (AEO + GEO)

- [ ] **پاسخ مستقیم ۴۰–۶۰ کلمه** بلافاصله بعد از H1 (بلاک‌کوت اول) — برای snippet و استناد AI
- [ ] **FAQ حداقل ۴ سوال** در انتهای هر مقاله/صفحه خدمت + اسکیمای FAQPage
- [ ] ساختار H2/H3 سلسله‌مراتبی؛ هر H2 یک پرسش/عنوان جستجوی واقعی بیمار
- [ ] **آمار داخل جمله** (قابل استناد): «بیش از ۱٬۰۰۰ جراحی موفق»، «۲ تا ۴ هفته نقاهت» — اعداد دقیق در متن
- [ ] حداقل ۵ **لینک داخلی**: مقصد فقط صفحات پیلار (`/jaw-surgery`, `/dental-implant`, `/chin-surgery`, `/costs`, …) یا مقالات دیگر؛ لینک داخلی به صفحه BOFU مرتبط الزامی
- [ ] کلمه کلیدی کانونی در H1، پاراگراف اول، یک H2 و اسلاگ
- [ ] برند «دکتر حامد کرمانی» حداقل ۲ بار + CTA مشاوره/تلفن در پایان
- [ ] **بدون تاریخ** در متن و عنوان (تصمیم کاربر)؛ فقط متادیتای نامرئی (schema/sitemap lastmod)
- [ ] **بدون تکرار**: جمله‌های ۶+ کلمه نباید با مقاله دیگری مشترک باشد (`src/lib/agents/uniqueness.ts` + `qa-articles.ts`)
- [ ] حجم مقاله ۱۵۰۰+ کلمه؛ پاراگراف‌های ۳–۵ جمله‌ای؛ بدون آب‌بندی توخالی
- [ ] پارسر سایت محدودیت دارد: بدون بک‌تیک، `${}`، لینک http خام، تگ HTML و عکس مارک‌داون در بدنه
- [ ] **RAG-chunk friendly**: هر سکشن زیر یک H2 حدود ۱۰۰–۱۵۰ کلمه با جمله آغازین خودکفا (اینترفیس بهیچ وابستگی به سکشن قبل نداشته باشد)

## ۴) چک‌لیست تجربه و طراحی (SXO + web-design-guidelines)

- [ ] زبان بصری سایت حفظ شود: زمینه Laki `#0d0e0b`، طلایی `#c9a13b`، فونت فارسی سایت؛ از الگوهای عمومی «AI‌ساخت» (کارت‌های آیکونی سه‌تایی، گرادیان بنفش، هیرو وسط‌چین کلیشه‌ای) پرهیز — مرجع: `agent-skills/taste-skill/`
- [ ] `color-scheme` تیره + `themeColor` + `viewportFit: cover` حفظ
- [ ] دکمه‌های آیکونی `aria-label` دارند؛ فرم‌ها `label`/`aria-label` + `autocomplete` + `inputmode` درست
- [ ] فوکوس قابل مشاهده (`focus-visible`)؛ هیچ `outline-none` بدون جایگزین
- [ ] انیمیشن فقط `transform/opacity` + احترام به `prefers-reduced-motion`؛ بدون `transition: all`
- [ ] اعداد و تاریخ با اعداد فارسی و `Intl` (بدون فرمت هاردکد)
- [ ] CTA تلفن/واتس‌اپ/نوبت در دسترس (sticky موبایل + پایان هر مقاله)
- [ ] قبل از merge: اسکرین‌شات playwright-cli دسکتاپ ۱۴۴۰ + موبایل ۳۹۰ + کنسول بدون خطا

## ۵) ابزارهای ممیزی و دور نگه‌داری

| ابزار | فرمان | دور |
|---|---|---|
| `bun scripts/qa-articles.ts` | QA قرارداد مخزن (چک ۱–۹ + هشدارهای AEO/SXO چک ۱۰) | قبل از هر انتشار |
| `node scripts/audit-aeo-sxo.mjs` | ممیزی AEO/SXO زنده همه مقالات (امتیاز هر دو روی ۱۰۰) | هر ۱۰ مقاله |
| `cd tools/seo/geo-optimizer-skill && uv run geo audit --url https://dr-kermani.com` | امتیاز GEO | هر ۱۰ مقاله |
| `playwright-cli` اسکرین‌شات + `console` | بازبینی بصری | هر تغییر UI |
| `mcp-gsc` (`.mcp.json`) | پرسش از داده سرچ‌کنسول | ماهانه |
| `open-seo` + `docs/seo/keyword-plan.md` | تحقیق کلمه | پیش از هر مقاله جدید |

خط تولید محتوا (ایده → بریف → نوشتن → گیت → انتشار → ایندکس → اندازه‌گیری) با
claude-seo پیکربندی شده است: **`docs/seo/content-pipeline.md` مرجع رسمی است** —
گیت‌های سخت مقاله تازه در `src/lib/agents/publish.ts` و قواعد نویسنده در
`src/lib/agents/creative.ts` نگهداری می‌شوند.

سوابق امتیاز GEO: **۲۰۲۶-۱۰-۲۳ → ۷۷/۱۰۰**، **۲۰۲۶-۱۰-۲۴ → ۸۱/۱۰۰**، **۲۰۲۶-۱۰-۲۵ → ۹۴/۱۰۰**.
سوابق ممیزی AEO/SXO مقاله‌ها: **۲۰۲۶-۱۰-۲۵ → AEO ۶۵ / SXO ۹۰** (پایه — قبل از فیکس h3 سوال‌ها و کوتاه‌سازی title/desc).
یافته‌های باز شناخته‌شده (پذیرفته‌شده یا در انتظار): تاریخ‌های نامرئی (تصمیم کاربر)،
نیم‌فاصله به‌عنوان «کاراکتر نامرئی» (false positive فارسی)، متن‌های sr-only
(الگوی دسترسی‌پذیری، نه کلوکینگ)، فقدان لینک‌های Knowledge Graph خارجی
(ویکی‌پدیا/لینکدین وجود ندارد تا اضافه شود)، فاقد `**` توپر در مقالات قدیمی
(گیت سخت فقط برای مقاله‌های تازه).
