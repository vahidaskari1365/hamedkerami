## گیت‌های AEO/SXO (فاز ۴) — چک‌لیست دقیق

### سطح مقاله تازه — `publish.ts` (رد = عدم انتشار)

| گیت | معیار | استاندارد |
|---|---|---|
| AEO-۱ | پاسخ مستقیم (بلاک‌کوت اول) | ۲۵–۹۰ کلمه |
| AEO-۲ | تیتر پرسشی (H2/H3 با «؟») | ≥ ۲ |
| GEO-۳ | عدد/آمار داخل جمله | ≥ ۳ |
| SXO-۴ | لینک داخلی BOFU (costs/appointment/contact/پیلارها) | ≥ ۱ |
| SXO-۵ | برجسته‌سازی `**` | ≥ ۲ |
| SEO | طول کل | ≥ ۱۵۰۰ کلمه |
| SEO | لینک داخلی | ≥ ۴ |
| AEO | FAQ با `###` | ≥ ۴ سوال |
| فنی | بک‌تیک/`${}`/تگ HTML/لینک http/عکس مارک‌داون | ۰ مورد |
| اعتماد | تلفن مطب + نام دکتر/فلوشیپ | الزامی |

### سطح مخزن — `scripts/qa-articles.ts` (قبل از هر اجرای blog-agent)

چک‌های ۱–۹ قراردادی + چک ۱۰ (AEO/SXO) به‌صورت هشدار برای مقالات موجود؛
مقالات تازه با گیت سخت `publish.ts` کنترل می‌شوند تا خط تولید نایستد.

### سطح قالب HTML — `src/app/blog/[slug]/page.tsx` + `article-body.tsx`

- سوال‌های FAQ با `<h3>` واقعی داخل `<summary>` رندر می‌شوند (تطابق FAQPage schema ↔ متن مرئی)
- `<title>` با `serpTitle` به ≤۶۰ کاراکتر کوتاه می‌شود (H1 و og:title کامل می‌ماند)
- توضیح متا با `serpDescription` به ≤۱۶۰ کاراکتر برش کلمه‌ای می‌خورد
- باکس `data-answer` (پاسخ کوتاه) + TOC دسکتاپ/موبایل + باکس نویسنده + نوار CTA

## ممیزی دوره‌ای

```bash
# ممیزی AEO/SXO زنده همه مقالات (AEO و SXO هر کدام روی ۱۰۰)
node scripts/audit-aeo-sxo.mjs

# QA قرارداد مخزن
bun scripts/qa-articles.ts

# ممیزی GEO (استناد AI)
cd tools/seo/geo-optimizer-skill && uv run geo audit --url https://dr-kermani.com
```

گزارش‌ها در `docs/seo/article-audit/` نگهداری می‌شوند.

## شکاف‌های شناخته‌شده (پذیرفته‌شده)

- مقالات قدیمی (۱۸ مقاله مخزن + بخشی از دیتابیس) فاقد `**` توپر هستند — گیت فقط مقاله‌های تازه را می‌سنجد؛ غنی‌سازی مقالات قدیمی باید از مسیر بازنویسی ایجنت (نه رجکس) انجام شود
- مقالات قدیمی ممکن است تیتر پرسشی کمتر از ۲ داشته باشند — در بازنویسی بعدی هر مقاله برطرف می‌شود
